# Changelog

All notable changes to this project are documented in this file.

## [1.0] - 2026-09-27
- Initial stable release (1.0).
- Features:
  - Read-only web app that reads an Excel workbook from `data/` and shows each sheet as a button.
  - Person filter showing apartments per person.
  - Month columns restored and visible.
  - Mobile optimizations and responsive sidebar.
  - Removed interactive keyboard shortcuts and play/expand buttons per user preference.
  - Summary rows kept at bottom and excluded from person-specific filters.
  - Version constant added (`VERSION = '1.0'`).
